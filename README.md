# 我的纳指100定投计划（QQQ · 每周定投 · 跌多多投 / 趋势定投）

**网站地址：<https://gini10484-afk.github.io/nasdaq100-dca/>**

一个每天自动更新的小网站。打开它就能看到：

- **下个定投日该投多少钱**：默认用“综合策略”（一直上涨时照常投、涨太多少投，跌破 200 日均线后分档加码），也可以切换成“跌多多投”（离最高点跌得越多投得越多）
- **QQQ 历史上跌了多少、比 200 日均线高多少**：图上画出了加码和少投的分界线
- **这些规则过去管不管用**：普通定投、跌多多投、趋势定投三种一起回测对比，还会换不同开始年份再比一遍
- **用之前要知道的事**：最多一周要投多少、最长连续加码多久、历史上最长多久才回本
- **我的资金计划**：填上人民币闲钱、每月新增闲钱和拿出来投资的比例，算出每次基础金额和下次该投多少（保守 / 平均两种）
- **每年固定投一笔会怎样**：比如每年 35 万人民币，从某一年一直投到现在，按当年汇率换汇后能算出总投入、现在市值和年化
- **我的买入记录**：记下每周实际买了多少，和规则建议对比，算出持仓、市值和平均成本
- **定投日提醒**：定投日北京时间 20:00，GitHub 发邮件（和 GitHub App 推送）告诉你这周该投多少

网站放在免费的 GitHub Pages 上。每个美股交易日收盘后（北京时间早上 6:30 左右），GitHub 会自动拉取最新行情并更新网站，手机和电脑都能打开。

> 这个网站不预测明天涨跌，没有人能稳定做到这件事。它做的是：用你自己定的规则，根据“现在已经跌了多少”算出这周该投多少，并用历史数据检验这个规则。

## 规则是什么

网页最上面可以选**定投策略**（两个）和**多久投一次**（每周一次 / 每个交易日）。两个策略都用**定投日前一个交易日的收盘价**计算，不会偷看当天价格；默认每周一定投，基础金额 $100。

选“每个交易日”时，每个美股交易日都按同样的规则投一次，页面上的“每周”会变成“每次”。用真实数据回测，每日和每周的年化几乎一样（比如 2016 年初到现在：每周 20.77%、每日 20.73%），差别主要在手续费和麻烦程度上——单笔金额会小很多，先确认券商没有最低手续费或最低下单金额。

### 默认：综合策略（趋势定投 + 跟近一年最高点比 + 上涨中回调不加码）

先看 QQQ 在 **200 日均线**（最近 200 个交易日收盘价的平均，大约 10 个月）上面还是下面，再看离**近一年最高点**跌了多少：

| 情况 | 怎么判断 | 这周投入 |
|---|---|---|
| 下跌趋势 | 跌破 200 日均线，离近一年最高点跌不到 20% | 基础金额 × 1.5 |
| 下跌趋势 | 跌破均线，跌 20% – 30% | 基础金额 × 2 |
| 下跌趋势 | 跌破均线，跌 30% 以上 | 基础金额 × 3 |
| 涨太多 | 比均线高 15% 以上 | 基础金额 × 0.5 |
| 其他时候 | 在均线上方 | 基础金额 × 1 |

- 一直上涨时不会停投：大部分时间照常 ×1，只有涨得离均线太远时少投一半。
- 用 1999 年以来的真实数据回测（截至 2026-09-10），和“每周固定金额”的普通定投比：2000–2025 年里每 10 年一段、共 17 段，年化收益率 16 段更高、没有一段更低，平均高约 0.5 个百分点，平均多投约 19% 的钱，最长连续加码 64 周。用 2013 年以前的数据选出这个组合，放到 2013 年以后检验，结论也成立。
- **要知道：** 它年化更高，主要是因为下跌时多投了钱。如果总共能投的钱一样多（没用完的钱先留着等下跌），历史上每周按时全部投进去反而更好。所以加码用的钱最好是本来不会拿去投资的钱。
- 在“调整规则”里可以把“上涨中回调”（在均线上方、离最高点跌了 10% 以上）的倍数改成 1.5，就是加码版的趋势定投。

### 另一个策略：跌多多投

| QQQ 离最高点跌了 | 这周投入 |
|---|---|
| 不到 10% | 基础金额 × 1 |
| 10% – 20% | 基础金额 × 1.5 |
| 20% – 30% | 基础金额 × 2 |
| 30% 以上 | 基础金额 × 3 |

跟“历史最高点”比时，2000 年那种跌完十几年才回来的熊市里会连续加码很多年（回测里最长 763 周，总投入是普通定投的 2 倍左右）；跟“近一年最高点”比压力小很多。

基础金额、定投日、策略、两个策略的分档和倍数，以及“跟历史最高点比”还是“跟近一年最高点比”，都可以直接在网页上改。改完信号和回测会马上重新计算，设置保存在你自己的浏览器里。过去的回测结果不代表未来。

## 部署到网上（大约 15 分钟，只需要做一次）

### 第 1 步：注册 GitHub

打开 <https://github.com/signup> 注册一个免费账号，并验证邮箱。

### 第 2 步：新建一个公开仓库

1. 登录后点右上角 **＋** → **New repository**。
2. **Repository name** 填 `nasdaq100-dca`（也可以用别的名字，最后网址会跟着变）。
3. 选择 **Public**（免费账号的 GitHub Pages 需要公开仓库。仓库里只有代码和公开的行情数据，你在网页上的设置不会上传）。
4. 下面的 “Add a README” 等选项**都不要勾**，点 **Create repository**。

### 第 3 步：上传文件

1. 在刚建好的仓库页面上，点 **uploading an existing file** 这个链接。
2. 在 Mac 的“访达”里打开 **文稿 → nasdaq100-dca**，按 **Command + A** 全选**文件夹里面的内容**（`docs`、`scripts`、`tests`、`workflow`、`README.md`、`requirements.txt`），拖到网页的上传区域。不要拖外面的 `nasdaq100-dca` 文件夹本身。
3. 等文件列表出来后，点页面底部绿色的 **Commit changes**。

### 第 4 步：打开 GitHub Pages

1. 点仓库上方的 **Settings**，左侧点 **Pages**。
2. **Build and deployment → Source** 选择 **GitHub Actions**。

### 第 5 步：添加“每天自动更新”的设置文件

这个文件必须放在仓库的 `.github/workflows/` 文件夹里。这是隐藏文件夹，拖拽上传时经常被漏掉，所以在网页上单独新建：

1. 回到仓库首页（点左上角的仓库名），点 **Add file → Create new file**。
2. 文件名输入：`.github/workflows/update-and-deploy.yml`（输入 `/` 时会自动变成文件夹）。
3. 在电脑上用“文本编辑”打开 `nasdaq100-dca/workflow/update-and-deploy.yml`，按 Command + A 全选、复制，再粘贴到网页的大输入框里。
4. 点 **Commit changes**。

提交后，自动更新会马上开始第一次运行。

想要定投日提醒，再用同样的方法新建 `.github/workflows/weekly-reminder.yml`，内容复制 `workflow/weekly-reminder.yml`。

### 第 6 步：确认运行成功

1. 点仓库上方的 **Actions**。
2. 左边点 **每日更新数据并发布网站**，能看到正在运行的记录（黄色圆点）。
3. 如果没有运行记录，点右边 **Run workflow**，再点绿色的 **Run workflow**。
4. 等 2–3 分钟，出现绿色对勾 ✅ 就说明成功了。

### 第 7 步：打开你的网站

回到 **Settings → Pages**，页面顶部会显示网址，一般是：

```
https://你的用户名.github.io/nasdaq100-dca/
```

用手机打开，加到收藏或主屏幕，以后每周定投前看一眼就行。

## 以后每天会自动发生什么

1. 每个美股交易日收盘后，GitHub Actions 从 Yahoo Finance 拉取 QQQ 的完整历史行情。
2. 数据先检查一遍：行数突然变少、日期乱序、单日涨跌超过 25%、和旧数据对不上，都会放弃这次更新，保留旧数据。
3. 检查通过就保存到 `docs/data.json`，并重新发布网站。
4. 如果 Yahoo 暂时连不上，会自动换备用接口。全部失败时，网站继续显示旧数据并出现黄色提醒，GitHub 也会发邮件通知你，通常第二天会自己恢复。

## 我的资金计划

网站上“我的资金计划：这周投多少”可以按你自己的钱算金额：

- 填“现在的闲钱”“每月新增闲钱”（人民币）、“拿出多少投资”（比如 30%）、“现在这笔分多久投完”和汇率（默认是 2026-09-11 的市场中间价，请按换汇时的实际价格改）。
- 金额会按你选的频率算：每周定投给的是每周金额，每日定投给的是每次（每个交易日）金额。
- 会同时给出两个金额，点一下选择：
  - **保守**：用 1999 年以来的数据检查，不管从哪一周开始，按规则加码都不会把钱投光。平时会攒下一些没投的钱，留给大跌时加码。
  - **平均**：长期平均下来刚好把能拿出的钱投完；遇到大跌连续加码时，要另外准备钱（页面会写出历史上最难的时候还差多少）。
- 点“把每周基础金额设为 …”，上面的信号、回测和买入记录都按这个金额算。
- 这些数字只保存在当前设备的浏览器里，不会上传。定投日提醒仍按仓库里的默认基础金额 $100 算，按提醒里的倍数乘你自己的基础金额就行。

## 每年固定投一笔会怎样

如果你是“每年拿一笔钱出来投”（比如每年 35 万人民币），网站上“每年固定投一笔会怎样”可以直接算：

- 填每年投多少人民币、从哪一年开始，再选怎么投：
  - **每年年初一次性投**：每年第一个交易日一把投进去。
  - **平摊到每次定投**：把这一年的钱分到每次定投（每周 52 次 / 每日 252 次）。
  - **按当前策略**：也是摊到每次定投，但按上面选的策略乘倍数；跌的时候要多投，只能花前面攒下的钱，所以最后可能剩一些现金。
- 每年的钱按**当年的平均汇率**换成美元（1999–2003 是当时的固定汇率 8.277，2004 年起用欧洲央行的年均值；表在 `docs/strategy.js` 的 `CNY_RATES`，每年补一行就行），现在的市值按“我的资金计划”里填的汇率换回人民币。
- 展开“每年那笔钱现在值多少”能看到每一年投进去的钱现在各值多少、翻了几倍。
- 举个例子：1999 年起每年年初投 ¥35 万，到 2026 年 9 月共投入 ¥980 万，现在约 ¥1.06 亿，人民币口径年化 14.10%（只看美元 14.84%）。摊到每周投是 14.49% / 15.25%。
- 没有算手续费、换汇点差和分红预扣税；每年超过 5 万美元也超出了个人购汇便利化额度。这只是历史回测，不是收益承诺。

## 我的买入记录

网站上“我的买入记录”可以记下每次实际买入的日期、金额和成交价：

- 选好日期后，会自动填入当天收盘价和规则建议金额，改成你的实际数字再点“添加记录”。
- 每一笔都会显示规则建议投多少、你是多投还是少投，上方汇总持有股数、现在市值、浮动盈亏和平均成本。
- 记录**只保存在当前设备的浏览器里**，不会上传到 GitHub（仓库是公开的）。清理浏览器数据会删掉记录，所以要定期备份。
- **发到邮箱**：在“备份邮箱”填好自己的邮箱（只保存在这台设备，不会写进公开代码），点“发到邮箱”会打开邮件 App，收件人、标题和备份内容都填好了，点发送就行。恢复时点“粘贴导入”，把邮件里两条横线之间的内容粘贴进去。
- **导出备份 / 导入备份**：把记录存成 .json 文件，换手机或电脑时在新设备上导入。

## 定投日提醒

仓库里的“定投日提醒”工作流（`.github/workflows/weekly-reminder.yml`）每个工作日北京时间 20:00 检查一次：

- 如果今天（美东时间）是定投日，就在仓库的 **Issues** 里发一条提醒并 @你，写明这次按规则投多少、QQQ 离最高点跌了多少、美股几点开盘，并附上另一个策略这次该投多少（网页上切换了策略也能对上）。
- GitHub 会把提醒发到你注册 GitHub 用的邮箱；手机装了 **GitHub App** 并登录，还会收到推送。
- 新提醒发出时，上一条会自动关闭。
- 想马上试一下：打开 **Actions → 定投日提醒 → Run workflow**，会发一条测试提醒。
- 提醒按 `docs/strategy.js` 里的 `DEFAULT_CONFIG` 计算，`strategy` 决定主提醒按哪个策略（`"tiered"` 跌多多投，`"trend"` 趋势定投），`frequency` 设成 `"daily"` 就每个工作日都提醒。你在网页上改的设置只存在自己的浏览器里，GitHub 看不到；想让提醒也按新设置算，就改 `DEFAULT_CONFIG`。
- 如果收不到邮件：在 GitHub 右上角头像 → Settings → Notifications 里，确认 “Participating, @mentions and custom” 勾选了 Email。

## 常见问题

**Actions 里出现红叉 ❌ 怎么办？**
点进去看是哪一步失败了。如果是“更新行情数据”失败，多半是数据源暂时不可用，网站还会用旧数据正常发布，等第二天自动重试就好。如果是“发布到 GitHub Pages”失败，请检查第 4 步的 Source 是否选了 **GitHub Actions**。如果 Actions 页面什么都没有，请检查第 5 步的文件名是不是正好是 `.github/workflows/update-and-deploy.yml`。

**收到邮件说定时任务被停用了？**
GitHub 会暂停长期没有活动的仓库的定时任务。打开 **Actions**，点 **Enable workflow** 就能恢复。

**想改默认规则（网页第一次打开时的设置）？**
改 `docs/strategy.js` 最上面的 `DEFAULT_CONFIG`。比如想默认用跌多多投，把 `strategy: "trend"` 改成 `strategy: "tiered"`；想默认每个交易日都投，把 `frequency: "weekly"` 改成 `frequency: "daily"`。在 GitHub 网页上点开这个文件，点铅笔图标编辑，然后 **Commit changes**。提交后网站会自动重新发布，定投日提醒也会跟着变。

**想在自己电脑上预览？**
在 `docs` 文件夹里运行 `python3 -m http.server`，再打开 <http://localhost:8000>。不能直接双击 `index.html`，因为浏览器不允许网页这样读取数据文件。需要先有行情数据，可以先按第 6 步在仓库里运行一次，再把 `docs/data.json` 下载下来。

**想检查计算逻辑？**
```bash
node --test tests/strategy.test.js            # 两个策略、每周/每日、回测、资金计划、每年一笔和买入记录（31 项）
node --test tests/reminder.test.js            # 定投日提醒（8 项）
python3 -m unittest tests/test_update_data.py # 数据更新脚本（需要 pandas）
```
